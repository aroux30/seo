# AI SEO OS

پلتفرم هوشمند سئو با هوش مصنوعی

## Stack
- **Backend:** FastAPI + PostgreSQL + Redis + Celery
- **Frontend:** Next.js 14 (App Router) + Tailwind CSS
- **AI:** Multi-provider (Gemini, OpenAI, Claude, DeepSeek) with auto key rotation
- **Deploy:** Docker Compose + Nginx + SSL

## Quick Start
```bash
# Development
docker-compose up -d

# Production
./deploy.sh
```
